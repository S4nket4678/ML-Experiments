# Logistic Regression – Binary Classification

## Experiment
Implement Logistic Regression to predict whether a student will pass or fail based on:

- Hours Studied
- Previous Score

## Dataset
The dataset contains 100 student records.

### Columns
- `Hours_Studied` – Number of hours studied
- `Previous_Score` – Student's previous score
- `Result` – Target variable (`0 = Fail`, `1 = Pass`)

## Objective
Train a Logistic Regression model and predict the result for new students.

## Output
The experiment displays:
- Model predictions
- Accuracy
- Confusion Matrix
- Classification Report
